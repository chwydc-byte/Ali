# APK Factory — تطوير على المشروع الموجود

هذه نسخة مطوّرة من مشروع `AIFactoryApp` الموجود، وليست مشروعًا جديدًا من الصفر. تم تبسيط الواجهة العربية وإضافة كشف مبدئي لنوع المشروع من أسماء الملفات، إرشادات بناء حسب المحرك، شاشة معاينة توضّح حدود الدعم، مساعد تحليل نصي لأخطاء البناء، ومتطلبات توقيع APK.

## الميزات الحالية فعليًا
- اختيار ZIP أو مجلد أو ملفات متعددة من الهاتف عبر WebView.
- قراءة فهرس ZIP لتحديد أسماء الملفات وأنواع المشاريع المحتملة، دون استخراج محتوى الأرشيف.
- التعرف المبدئي على Android/Gradle وFlutter وReact Native/Expo وGodot وUnity ومشاريع الويب.
- عرض خطوات البناء المناسبة لكل نوع، مع سجل محلي للمشاريع.
- تحليل أولي لنص خطأ يقدمه المستخدم.
- توضيح متطلبات توقيع APK.

## حدود مهمة — لا ندّعي ميزات غير منفذة
- هذه النسخة لا تستخرج ملفات ZIP إلى مساحة عمل، ولا تنفّذ Gradle/Flutter/Unity/Godot، ولا تبني أو توقّع APK مستوردًا من داخل التطبيق.
- المعاينة حاليًا إرشادية وليست تشغيلًا حقيقيًا للمشروع. تشغيل المشاريع يتطلب استخراجها وربطها بمحرك مناسب.
- إصلاح الأخطاء يقترح خطوات من نص الخطأ ولا يغيّر الملفات تلقائيًا.
- لا يوجد محوّل واحد يستطيع بناء كل مشروع بلا أدواته واعتمادياته. البناء الهجين يحتاج محركات محلية مختلفة، وقد تحتاج بعض الأنواع بيئة بناء خارجية أو إعدادات ثقيلة.
- لم يُدمج نموذج AI حقيقي في هذه الحزمة.

## بناء تطبيق APK Factory نفسه على Termux
يستخدم `build.sh` أدوات Android منخفضة المستوى (`ecj`, `dx`, `aapt2`, `apksigner`, `android.jar`). نفّذ البناء فقط بعد توفرها فعليًا. لم يتم إنشاء APK جديد في بيئة إعداد هذه الحزمة، لذلك لا تعتبر أي APK قديم دليلًا على نجاح هذه التعديلات.

## المسار التالي لتحويل المشاريع فعلًا
1. إضافة طبقة تخزين واستخراج ZIP آمنة إلى مجلد مشروع مستقل.
2. إضافة منفّذ بناء محلي Android/Gradle مع التقاط سجل الخرج.
3. ربط معاينة HTML بالمحتوى المستخرج، وإضافة تشغيل خارجي/محاكي للأنواع الأخرى.
4. دعم Flutter/Godot/Unity فقط عند توافر SDK والمحركات والقوالب المطلوبة.
5. تنفيذ توقيع APK بعد نجاح البناء، مع حفظ المفتاح محليًا وعدم رفعه.
